# Portfólio pessoal de Lucas Matos — design

## Objetivo

Criar uma página única, limpa e responsiva para Lucas Matos, estudante de Engenharia da Computação no CEUMA (Maranhão), que possa ser entregue por meio de um repositório no GitHub e publicada no GitHub Pages.

## Direção visual

- Tema escuro profissional, com azul elétrico usado apenas em destaques e ações.
- Tipografia sem serifa, espaçamento amplo e navegação discreta.
- Layout acessível em celular e desktop, sem bibliotecas ou etapas de instalação.

## Conteúdo

1. Abertura: nome, formação e chamada para os projetos.
2. Sobre: 19 anos, estudante de Engenharia da Computação, CEUMA — Maranhão, com interesse em tecnologia aplicada.
3. Projetos:
   - Grupo SP: plataforma de alocação de espaços, inspirada no modelo Airbnb; trabalho em grupo com JavaScript e Lovable.
   - Grupo Everest: monitoramento de portos com Java, React e APIs de clima/tempo; o trabalho recebeu elogio da empresa parceira.
4. Certificações: resumo dos cursos de Coursera e parceiros Google, IBM e Microsoft, incluindo "The Nuts and Bolts of Machine Learning".
5. Contato: link para GitHub de Lucas, `https://github.com/lucas-dll`.

## Arquitetura e publicação

- Arquivos estáticos: `index.html`, `style.css` e `script.js` opcional.
- Sem build, framework, back-end ou coleta de dados.
- Publicação por GitHub Pages a partir da raiz do repositório.

## Comportamento e qualidade

- Navegação por âncoras com rolagem suave.
- Links externos abrem com proteção adequada.
- Design responsivo, contraste legível e estrutura HTML semântica.
- Verificação local abrindo o `index.html` e inspeção dos links e das larguras de tela.
